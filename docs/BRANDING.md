# Identité visuelle de SAWM Defense

L’interface utilise le noir, le blanc et des gris neutres. Les niveaux de gravité et les états restent indiqués par des mots, afin que la couleur ne soit jamais la seule information.

L’icône conserve la fleur géométrique SAWM / Basira fournie par le propriétaire. Sa variante application a été créée le 12 novembre 2026 avec l’outil intégré de génération d’images, à partir de cette référence. Les fichiers natifs ICO et ICNS sont des conversions de la même image ; ils ne contiennent aucune information Cloud.

- Image : [`sawm-defense-icon.png`](../sawm_defense/assets/sawm-defense-icon.png).
- Windows : [`sawm-defense.ico`](../sawm_defense/assets/sawm-defense.ico).
- macOS : [`sawm-defense.icns`](../sawm_defense/assets/sawm-defense.icns).
